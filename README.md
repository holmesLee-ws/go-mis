# go-mis

경영정보시스템(MIS)을 AI 튜터와 함께 익히는 학습 워크스페이스입니다. 정보시스템 전략과 IT 거버넌스, ERP 같은 업무 시스템과 데이터, 시스템 도입(요구·선정·계약·전환·검수), IT 운영과 클라우드를 다룹니다. 한국의 법·제도(전자문서법, 전자서명법, 전자금융거래법, 소프트웨어 진흥법, 클라우드컴퓨팅법 등)를 뼈대로 하고, 국제 기준(ISO/IEC 38500·20000, COBIT, ITIL 등)을 비교 축으로 씁니다.

정해진 강의 자료는 없습니다. 이 리포에는 커리큘럼의 큰 지도와 튜터의 행동 규칙만 있습니다. 도식과 조사 자료를 조합한 HTML, 업무에 쓸 산출물 초안은 대화하면서 튜터와 함께 그 자리에서 만듭니다.

## 시작하기

준비물은 Git, [GitHub CLI](https://cli.github.com)(`gh`), Claude Code 또는 Claude Desktop입니다. 비공개 리포이므로 먼저 GitHub에서 보낸 초대를 수락하고, 터미널에서 `gh auth login`으로 로그인합니다. 그 밖의 설치는 필요 없습니다.

```bash
cd ~/Desktop
gh repo clone holmesLee-ws/go-mis
```

**Claude Code**

```bash
cd ~/Desktop/go-mis
claude
```

처음 열면 이 폴더를 신뢰하는지 묻습니다. 기본 선택은 「No, exit」이므로 Enter만 누르면 종료됩니다. **아래 화살표로 「Yes, I trust this folder」를 고른 뒤 Enter**를 누르세요. 그래야 학습 기록 저장과 자료 조사를 튜터가 묻지 않고 진행합니다.

**Claude Desktop**

Code 탭에서 데스크탑의 `go-mis` 폴더를 선택합니다. Chat 탭이 아니라 Code 탭이어야 튜터 규칙이 적용됩니다.

어느 쪽이든 「안녕」이라고 입력하면 시작합니다.

## 이렇게 진행됩니다

1. 왜 배우려는지, 일에서 정보시스템을 어떻게 다뤄 왔는지 짧게 묻고, 상황 문제 몇 개로 출발점을 찾습니다.
2. 모듈마다 먼저 상황 문제로 수준을 확인합니다. 이미 아는 내용이면 바로 넘어갑니다. 경험이 많으면 그 경험을 근거로 빠르게 확인합니다.
3. 내 회사의 업무와 시스템을 예로 들어 튜터와 대화하고, 튜터가 내 답을 반영한 HTML을 만들어 가며 익힙니다.
4. 모듈마다 실제 업무에 쓸 수 있는 산출물 초안(RFP 요구사항, SLA, 전환 계획, 권한표 등)을 함께 만듭니다.
5. 법령·고시·표준은 튜터가 그 자리에서 공식 출처(국가법령정보센터 등)를 열어 확인하고 출처를 남깁니다. 확인하지 못하면 그렇다고 말합니다.
6. 튜터는 내 답을 보고 너무 빠른지, 보강이 필요한지, 지루한지 판단해 속도와 방식을 바꿉니다.
7. 다음에 다시 열면 기록을 읽고 복습 질문 하나로 이어갑니다.

언제든 그냥 말로 요청하면 됩니다. 「이건 넘어가자」, 「너무 어려워」, 「그림으로 보여 줘」, 「우리 회사 얘기로 해 줘」처럼요.

| 명령 | 하는 일 |
|---|---|
| `/learn [모듈 또는 주제]` | 시작하거나 이어가기 |
| `/check [모듈 또는 영역]` | 빠르게 수준 확인하고 건너뛰기 |
| `/map` | 지금까지의 현황과 다음 모듈 |
| `/pace [너무 빠름·너무 느림·지루함·어려움]` | 속도와 난도 바꾸기 |

## 알아 둘 것

- 튜터는 법률 자문을 하지 않습니다. 법률·계약 판단이 들어간 산출물에는 「교육용 초안」 표시가 붙습니다. 실제 계약·신고 전에는 전문가 확인이 필요합니다.
- 회사 자료를 이야기할 때 개인정보, 계약 금액, 영업 비밀은 가리거나 예시 값으로 바꿔 주세요. 웹 조사 때는 질문과 주소가 외부 서비스로 전달됩니다.
- 보안, AI, 프로젝트 관리, 재무, 회계, 내부통제처럼 다른 go-* 워크스페이스가 깊게 다루는 주제는 필요한 만큼만 다루고 그 워크스페이스를 알려 줍니다.

## 구성

| 위치 | 내용 |
|---|---|
| [curriculum/map.md](curriculum/map.md) | 커리큘럼 지도와 출처 표 |
| [CLAUDE.md](CLAUDE.md), [tutor/](tutor/) | 튜터의 행동 규칙 |
| `.claude/` | 명령과 권한 설정 |
| `learner-template/` | 학습 기록의 빈 양식 |
| `learner/` | 내 기록, 내 HTML, 내 산출물 초안. 처음 시작할 때 생깁니다 |

`learner/`는 Git에서 제외되어 내 컴퓨터에만 남습니다. 그래서 `git pull`로 커리큘럼을 업데이트해도 기록이 충돌하지 않습니다. 컴퓨터를 옮길 때는 이 폴더를 직접 복사하세요.

## 튜터가 쓰는 권한

튜터는 묻지 않고 내 학습 기록, `learner/studio`의 HTML, `learner/work`의 산출물 초안을 쓰고, 웹을 조사하고, 만든 HTML을 열 수 있습니다. 그 밖의 파일을 고칠 때는 평소처럼 허락을 구합니다.
